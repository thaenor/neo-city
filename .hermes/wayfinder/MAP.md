## Destination

A **captivating mini-game POC** that validates whether Firebase Gen AI can drive a compelling gameplay loop. The core mechanic: **player behavior → Gen AI evaluates → world reacts physically.** Not a dialogue demo — a real game where what you say and do tangibly changes the environment, NPC relationships, and emergent outcomes.

Design thesis: *"The most fun you can have with an AI is trying to understand and manipulate it."*

## Core Loop (POC scope)

```
Walk up to NPC → Interact (text/action) → Gen AI evaluates your intent
  → Returns: witty dialogue + mood shift + world effect
  → World visibly changes (lights, bloom, sky, particles)
  → NPCs remember & reference your past behavior
  → Player explores: "What happens if I'm nice to everyone?" vs "What if I troll them?"
```

## Constraints

- Must work with existing Firebase Gen AI (gemini-2.0-flash) and its `parseActions` system
- Must use the existing 4 NPCs, city layout, dialogue system
- Zero new dependencies if possible
- Must still build + deploy via existing CI/CD
- POC = small. ONE tight loop, not a full game

## What's New Required

| Component | Why |
|-----------|-----|
| **MoodSystem.js** | Per-NPC mood vector (trust/anger/curiosity/amusement 0-100). Memory of past interactions. |
| **WorldEffects.js** | Reads aggregate mood → drives bloom, fog, sky, neon color, ambient light in real-time |
| **Enhanced Gen AI prompt** | Includes mood context + instructs AI to return mood shifts + world effect actions |
| **Mood UI indicator** | Subtle icon/bar showing NPC's current state (readable, not distracting) |
| **Glitch effect pass** | Optional: GlitchPass from three/examples to sell the "world is unstable" vibe |

## Exploration Questions

1. What **world effects** are the most viscerally satisfying? (bloom surging? lights flickering? sky tinting red?)
2. How does the Gen AI prompt need to change to produce **deterministic, parseable mood shifts** reliably?
3. What's the **minimum fun scenario** that proves the concept in 3 minutes of play?
4. Do we need a new NPC with a specific "mood manipulation" personality, or do the existing 4 work?

## Proposed POC Scenario

> **"Three Minutes at Echo's Bar"**
>
> One NPC (rename Nova → "Echo") stands at the central plaza. Echo is a Gen AI "mood mirror" — she reflects the city's emotional state. The player can talk to her 3-4 times. Each response is generated by Firebase Gen AI, evaluates what the player said, and:
> - Shifts Echo's mood (visible via glowing aura color)
> - Triggers a city-wide effect (bloom pulse, neon flicker, sky gradient shift, ambient sound)
> - Echo remembers previous interactions and references them
>
> After 3 exchanges, the city's "gestalt mood" locks in, and the player sees the cumulative effect. That's it. POC complete.
