# Triage Labels

The five canonical triage roles:

| Label | Meaning |
|-------|---------|
| `needs-triage` | Issue that hasn't been triaged yet |
| `needs-info` | Issue that needs more info from the reporter or a domain expert |
| `ready-for-agent` | Issue ready for an AI coding agent to work on |
| `ready-for-human` | Issue that needs a human maintainer (domain decision, scope call, design choice, security review) |
| `wontfix` | Issue the project has decided not to address |

When a skill says "apply the triage label", use these exact strings.
